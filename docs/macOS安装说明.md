# macOS 安装说明

## 选择正确版本

- Apple Silicon（M1、M2、M3、M4 等）：下载文件名包含 `arm64` 的版本。
- Intel Mac：下载文件名包含 `x64` 的版本。

## 安装步骤

1. 解压下载的 `.app.zip` 文件。
2. 将 `Days Count Down.app` 拖入“应用程序”文件夹。
3. 从“应用程序”打开。

当前软件未使用 Apple Developer ID 签名和公证。若首次启动被 macOS 阻止：

1. 打开“系统设置”。
2. 进入“隐私与安全性”。
3. 在安全提示区域确认应用来自本仓库，然后选择“仍要打开”。

公开分发包不包含用户倒计时、计划、缓存或日志。
